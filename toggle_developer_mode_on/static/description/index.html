App Overview

The Toggle Developer Mode app adds a convenient checkbox toggle to the Odoo systray, enabling users to seamlessly switch between normal mode and developer mode with a single click. This feature enhances productivity and streamlines the development experience, especially for developers and administrators managing Odoo instances.

Key Features:

  • Adds a developer mode toggle checkbox to the Odoo systray for quick switching
  • Toggle between normal mode and developer mode instantly without page refresh
  • Access debug information, field metadata, and model details in real-time
  • Perfect for developers, system administrators, and technical teams managing Odoo customizations
